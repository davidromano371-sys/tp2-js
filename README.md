# TP2 - Ejercicios de JavaScript

Repositorio de práctica del TP2 del curso Full Stack de RollingCode School.

**Autor:** David Romano

## Temas practicados

- Variables y tipos de datos
- Condicionales (if, else if, else, switch)
- Bucles (for, while, do...while)
- Strings y Math

## Cómo probar los ejercicios

1. Abrir el archivo `index.html`
2. En la línea del `<script>`, poner el ejercicio que se quiere probar, por ejemplo `js/ejercicio1.js`
3. Abrir `index.html` en el navegador (o con Live Server)
